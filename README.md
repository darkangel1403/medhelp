# MedHelp

**MedHelp** — настольное приложение для автоматизации работы регистратуры медицинского учреждения, разработанное на языке **C#** с использованием технологии **WPF** и базы данных **MS SQL Server**.

Программа предназначена для учета пациентов и врачей, организации электронной записи на прием, оформления вызовов врача на дом и ведения личных кабинетов пользователей.

---

## Основные возможности

### Работа с пациентами и врачами

* регистрация новых пользователей;
* ведение базы пациентов;
* управление справочником врачей;
* редактирование и удаление данных;
* поиск и фильтрация информации.

### Электронная регистратура

* запись на прием к врачу;
* просмотр доступных талонов;
* отмена и изменение записей;
* вызов врача на дом.

### Дополнительные возможности

* печать электронных талонов;
* экспорт данных в форматы:

  * Excel (.xlsx)
  * CSV (.csv)
  * JSON (.json)
  * TXT (.txt)
* формирование отчетов;
* возможность распечатать талон.

## Установка базы данных

База данных поставляется в виде резервной копии SQL Server (*.bak).

Для восстановления базы данных:

1. Установить Microsoft SQL Server Management Studio (SSMS) 2022.
2. Запустить SSMS и подключиться к локальному серверу.
3. В обозревателе объектов нажать правой кнопкой мыши на узел **«Базы данных»**.
4. Выбрать пункт **«Восстановить базу данных»**.
5. В разделе **«Источник»** выбрать пункт **«Устройство»**.
6. Нажать кнопку выбора файла и указать резервную копию базы данных (*.bak).
7. Выполнить восстановление базы данных.
8. Дождаться завершения операции.

После восстановления база данных будет доступна для работы приложения.

---

## Запуск приложения

1. Перейти в папку **EXE**.
2. Запустить файл **MedHelp.exe**.
3. Дождаться подключения к базе данных.

Если база данных недоступна или не была восстановлена, приложение выведет сообщение об ошибке подключения.

## Учетные записи

### Администратор

Логин:

```text
admin
```

Пароль:

```text
1234
```

Возможности администратора:

* управление врачами;
* управление пациентами;
* генерация расписания;
* просмотр статистики;
* полный доступ к данным системы.

### Пользователь

Для входа необходимо зарегистрировать новую учетную запись.

Доступные возможности:

* запись к врачу;
* вызов врача на дом;
* просмотр личного кабинета;
* экспорт собственных данных;
* печать талонов.
